# 同屋 Roomly · 合租生活管家

> 把合租里「不好意思开口」的事，交给系统去说。

**在线预览 → https://haoyu-zhu.github.io/roomly/**

一个面向合租年轻人的生活管理产品设计案例，覆盖：费用 AA 分摊、清洁值日排班、公共物品登记与提醒、室友公约管理。

## 核心观点

合租矛盾的根源不是「算不清」，而是**开不了口**和**看不见**。因此本产品的三条设计原则是：

1. **让系统当坏人** —— 所有催促以「管家」名义发出，界面不出现「XX 催你还钱」
2. **让沉默的付出被看见** —— 垫付、跑腿、家务折算成可见的家务币
3. **把规则前置到冲突之前** —— 公约走「提案 → 投票 → 生效 → 绑定后果」的流程

## 四大模块

| 模块 | 关键设计 |
|---|---|
| 账本 | 5 种分摊规则、最少转账笔数的一键结清、去人格化催收 |
| 值日 | 按耗时权重排班（保证每人周工作量均衡）、换班市场、打卡 |
| 物资 | 余量预测提醒、买了即自动入账均摊、采购轮值 |
| 公约 | 模板库、3/4 投票生效、条款绑定后果、入住签署 |

## 明确不做

不做在线支付、不做即时聊天、不做找房找室友、不做通用个人记账 —— 理由见站点「设计取舍」一节。

## 可交互原型

打开 https://haoyu-zhu.github.io/roomly/ 即可操作，数据保存在浏览器本地。

首次打开会进入欢迎页，点「开始体验 · 带我看一遍」会启动 **6 步功能讲解**：每一步真实切到对应页面、高亮那个按钮，并说明「做什么用 / 怎么操作」。「⋯ 房间」里可随时重看讲解或重置数据。

- 记一笔账（5 种分摊方式，实时预览分摊结果）
- 一键最优结清（债务图简化，把 10 笔交叉欠款压成 3 笔转账）
- 值日打卡 / 换班，按耗时权重的工作量均衡视图
- 物资登记采购 → 自动生成均摊账单入账本
- 公约提案投票，达到 3/4 实时生效
- 退租一键结算单

深链接：`?tab=bills` / `?tab=chores` / `?tab=supplies` / `?tab=pact`，`?sheet=settle` 可直接打开结清面板。
